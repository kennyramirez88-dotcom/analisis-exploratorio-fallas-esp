# Atribución del dataset

Este proyecto utiliza el archivo `features.csv` del dataset público **ESPset**.

## Fuente

- Título: ESPset
- Autores: Marcos Pellegrini, Flavio Varejão, Alexandre Rodrigues, Lucas Henrique Sousa Mello y Luciano Silva
- Publicación: Mendeley Data, versión 1, 2024
- DOI: [10.17632/m268jsw339.1](https://doi.org/10.17632/m268jsw339.1)
- Repositorio oficial: [NINFA-UFES/ESPset](https://github.com/NINFA-UFES/ESPset)
- Licencia de los datos: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)

El archivo `features.csv` se incluye sin modificaciones. El notebook, las visualizaciones y las interpretaciones de este repositorio corresponden al análisis realizado por Kenny Ramirez.

Artículo asociado: Varejão, F. M.; Sousa Mello, L. H.; Pellegrini Ribeiro, M.; Oliveira-Santos, T.; y Loureiros Rodrigues, A. (2024). *An open source experimental framework and public dataset for vibration-based fault diagnosis of electrical submersible pumps used on offshore oil exploration*. Knowledge-Based Systems, 288, 111452. [DOI 10.1016/j.knosys.2024.111452](https://doi.org/10.1016/j.knosys.2024.111452).
